## 1. 产品概述

苗棚任务状态与撤销复原平台是一个面向农业育苗场景的全栈管理系统，通过状态机驱动任务流转，支持管理员、育苗员和复核员三类角色协同工作。系统核心亮点是针对盘位、责任人、计划时间和备注的修改提供逐步撤销与重新应用能力，确保操作可追溯、可回退。

- 解决育苗过程中任务状态混乱、异常处理无追踪、操作不可逆的问题
- 目标用户为农业育苗基地管理人员与一线作业人员，提升任务管理效率与异常响应速度

## 2. 核心功能

## 3. 核心流程

### 3.1 任务状态流转

用户创建任务后，系统按状态机规则驱动任务流转。育苗员执行上盘、补苗、转移操作推动状态前进；复核员对异常情况进行审核确认；任何时刻可取消任务。

```mermaid
flowchart LR
    "待处理" -->|"开始执行"| "进行中"
    "进行中" -->|"提交复核"| "待复核"
    "待复核" -->|"复核通过"| "已完成"
    "待复核" -->|"复核驳回"| "进行中"
    "待处理" -->|"取消"| "已取消"
    "进行中" -->|"取消"| "已取消"
```

### 3.2 撤销/重做流程

用户对任务的盘位、责任人、计划时间、备注进行修改时，系统记录变更快照到操作历史栈。用户点击撤销时，从撤销栈弹出最新快照并恢复字段值，同时将该快照压入重做栈。用户点击重做时，反向操作。

```mermaid
flowchart TD
    "用户修改任务字段" --> "记录变更快照到撤销栈"
    "记录变更快照到撤销栈" --> "清空重做栈"
    "用户点击撤销" --> "弹出撤销栈顶快照"
    "弹出撤销栈顶快照" --> "恢复字段为快照前值"
    "恢复字段为快照前值" --> "将弹出快照压入重做栈"
    "用户点击重做" --> "弹出重做栈顶快照"
    "弹出重做栈顶快照" --> "应用快照后值"
    "应用快照后值" --> "将弹出快照压入撤销栈"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深翠绿 #1B5E20 搭配浅绿底 #E8F5E9，体现农业育苗主题
- 辅助色：琥珀色 #FF8F00 用于异常告警，石板灰 #37474F 用于文本
- 按钮风格：圆角8px，主操作实心填充，次操作描边，危险操作红色
- 字体：标题用 Noto Serif SC，正文用 Noto Sans SC
- 布局风格：左侧导航栏 + 右侧内容区，卡片式模块布局
- 图标：使用 Lucide React 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 登录页 | 登录表单 | 居中卡片，渐变背景，角色选择下拉框，密码输入框，登录按钮带加载态 |
| 仪表盘 | 任务进度 | 4个统计卡片（待处理/进行中/待复核/已完成），ECharts 环形图 |
| 仪表盘 | 异常分布 | ECharts 柱状图，按异常类型分色 |
| 仪表盘 | 人员负载 | ECharts 横向条形图，按人员显示任务数 |
| 棚区管理 | 棚区列表 | 响应式卡片网格，悬浮显示详情 |
| 棚区管理 | 盘位网格 | CSS Grid 棋盘格，空位灰色/使用中绿色/异常橙色 |
| 任务管理 | 任务列表 | 表格带斑马纹，状态标签彩色胶囊 |
| 任务管理 | 撤销/重做 | 底部固定工具栏，撤销/重做图标按钮+步数徽章 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1024px
- 仪表盘图表在中等屏幕下由2列变为1列
- 表格在小屏幕下横向滚动
- 盘位网格自动适应容器宽度

## 5. 技术约束

- 前端端口：8817
- 后端端口：8017
- 数据库：SQLite（单文件，便于部署）
- 认证：JWT 令牌，存储在 localStorage
- 前后端通过 CORS 代理通信
